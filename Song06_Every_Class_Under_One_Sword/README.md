# Album 82 – Sword Over the Empires

## Song 06 Every Class Under One Sword
Song 6 covers 2601–2700 and every major object class (Safe, Euclid, Keter, Thaumiel, Apollyon). It names official files in-range (2601, 2602, 2612, 2662, 2700 Teleforce, 2701) and links the 2401 hive, 2301 slayer-song, and 3001 red gap. All are banished by the Sword of Christ.
